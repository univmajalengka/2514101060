# 🌐 PABW — Pengembangan Aplikasi Berbasis Web

## 📝 Tentang Folder

Folder ini berisi kumpulan tugas dan praktikum mata kuliah **Pengembangan Aplikasi Berbasis Web (PABW)** yang dikerjakan selama perkuliahan di Program Studi Informatika, Universitas Majalengka.

Materi dan tugas di dalam folder ini berfokus pada proses perancangan, pengembangan, serta implementasi aplikasi berbasis web dengan memanfaatkan berbagai teknologi pemrograman web. Setiap tugas disusun berdasarkan pertemuan atau materi perkuliahan sebagai bentuk penerapan teori ke dalam praktik.
