## 📌 Tentang Proyek

**Keliling Dunia Majalengka** merupakan website informasi wisata yang memperkenalkan berbagai destinasi bertema negara-negara di dunia di Majalengka, Jawa Barat.

Website ini dikembangkan sebagai tugas mata kuliah Pengembangan Aplikasi Berbasis Web (PABW).

## ✨ Fitur Website

- 🏠 **Beranda** — Menampilkan halaman utama website wisata.
- 🗺️ **Destinasi Wisata** — Memperkenalkan berbagai spot wisata bertema dunia.
- 🎟️ **Paket Wisata** — Menampilkan pilihan paket dan harga tiket.
- 📸 **Galeri Foto** — Menampilkan dokumentasi tempat wisata.
- 🎬 **Video Wisata** — Menyediakan tautan video wisata dari YouTube.
- ℹ️ **Tentang Wisata** — Menampilkan informasi mengenai tempat wisata.
- 📍 **Lokasi dan Kontak** — Menyediakan informasi lokasi dan kontak.
- 📱 **Desain Responsif** — Menyesuaikan tampilan dengan ukuran layar perangkat.
- 🌙 **Mode Terang dan Gelap** — Memberikan pilihan tema tampilan.

## 🛠️ Teknologi yang Digunakan

| Teknologi    | Kegunaan                                 |
| ------------ | ---------------------------------------- |
| HTML5        | Membuat struktur halaman website         |
| CSS3         | Mengatur desain dan tata letak           |
| JavaScript   | Menambahkan interaksi dan fungsionalitas |
| Font Awesome | Menampilkan ikon                         |
| Google Fonts | Menggunakan jenis huruf pada website     |

## 🚀 Cara Menjalankan

1. Clone atau unduh repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan file `index.html` melalui browser atau ekstensi Live Server.
4. Pastikan koneksi internet tersedia untuk memuat sumber daya eksternal.
